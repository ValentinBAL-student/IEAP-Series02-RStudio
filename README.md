# IEAP – Series02 – RStudio

## Introduction

This repository contains the work completed for Series 02 of the IEAP course using RStudio and Quarto. The project focuses on statistical analyses performed on the provided dataset and collaborative development using Git and GitHub.


## Repository Link

https://github.com/ValentinBAL-student/IEAP-Series02-RStudio

## Objectives

The objectives of this repository are to:

- Perform the statistical analyses required in Series 02.
- Apply appropriate statistical tests and interpret their results.
- Learn collaborative version control using Git and GitHub.
- Produce a reproducible report using Quarto.

## Repository Contents

- `IEAP-Series02-RStudio.qmd` : Master Quarto document.
- `subdocuments/` : Individual Quarto files completed by each team member.
- `data/` : Dataset used for the analyses.
- `README.md` : Repository description and project overview.
- `LICENSE` : License information.
- Generated PDF report.

## Team Workflow

Each team member worked on an individual branch and completed assigned sections in separate Quarto documents. Changes were committed and pushed regularly to GitHub. Pull requests were reviewed by the other team members before being merged into the main branch.

## Summary of Work

The project included:

- Data exploration and descriptive statistics.
- Selection and application of statistical tests.
- Interpretation of results and discussion.
- Collaborative report writing using Quarto.
- Version control through Git and GitHub.
